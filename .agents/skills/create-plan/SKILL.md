# Skill: create-plan

## Description

Turn a complex request into a phased plan grounded in the current repository.

## Instructions

1. Verify the relevant repository facts before writing the plan.
2. State the goal, constraints, affected files, and documentation impact.
3. Split work into ordered phases with dependencies and executable exit conditions.
4. Keep product-specific details in the plan, not this generic skill.
5. Record validation commands and measurable evidence for each completed phase.
