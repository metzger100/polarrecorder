# Skill: grill-me-repo

## Description

Interview only for decisions that repository inspection cannot resolve safely.

## Instructions

1. Inspect existing patterns before asking a question.
2. Ask one material decision at a time and state the evidence-backed recommendation.
3. Cover ownership, data boundaries, configuration, output behavior, interaction, and documentation impact as relevant.
4. Record resolved choices in a compact decision log for the execution plan.
