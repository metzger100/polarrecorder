# Smell Prevention

**Status:** Current.

## Overview

This catalog lists every blocking rule enforced by the repository linters, custom checkers, and quality-gate scripts.
Treat each rule as fail-closed: fix the root cause in the same change instead of suppressing, deferring, or hiding it.

## Key Details

The source of truth for the commands is [quality gates](quality-gates.md). This file is the source of truth for what
those commands reject.

Maintained source has a zero-inline-suppression policy across source, tests, tools, configuration comments,
documentation code examples, and active plans. `npm run check:suppressions` owns the lexical scan, and ESLint's
`no-warning-comments` plus `noInlineConfig` independently rejects generated JavaScript directives. Negative fixtures are
created at runtime and are not committed as suppression comments.
